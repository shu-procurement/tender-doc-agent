# 招标智能审核系统 — 安装说明

## 环境要求

- Python 3.9 或以上
- pip（Python 包管理器）

---

## 第一步：克隆 / 下载项目

将 `PythonProject` 文件夹放到本地任意目录，例如：

```
~/Desktop/PythonProject
```

---

## 第二步：创建虚拟环境（推荐）

```bash
cd ~/Desktop/PythonProject
python3 -m venv .venv
```

激活虚拟环境：

- macOS / Linux：
  ```bash
  source .venv/bin/activate
  ```
- Windows：
  ```bash
  .venv\Scripts\activate
  ```

---

## 第三步：安装依赖库

将桌面上的 `requirements.txt` 复制到项目根目录，然后执行：

```bash
pip install -r requirements.txt
```

### 依赖库说明

| 库名 | 版本 | 用途 |
|------|------|------|
| flask | 3.0.3 | Web 框架，提供路由和模板渲染 |
| requests | 2.32.3 | 调用 Dify / DeepSeek / 百度 OCR 等外部 API |
| PyPDF2 | 3.0.1 | 读取 PDF 文件内容 |
| python-docx | 1.1.2 | 读取 Word（.docx）文件内容 |
| pymupdf | 1.24.5 | 高精度 PDF 文本提取（import fitz） |

---

## 第四步：配置 API 密钥

打开 `app.py`，找到第 15–66 行的配置区域，填入以下信息：

```python
# Dify 工作流 API 密钥（共 5 个工作流）
DIFY_API_KEY_RECOGNIZE  = "your_key_here"
DIFY_API_KEY_GENERATE   = "your_key_here"
DIFY_API_KEY_REVIEW     = "your_key_here"
DIFY_API_KEY_CONTRACT   = "your_key_here"
DIFY_API_KEY_COLLUSION  = "your_key_here"

# DeepSeek API 密钥
DEEPSEEK_API_KEY = "your_key_here"

# 百度 OCR（可选，用于图片文字识别）
BAIDU_OCR_API_KEY    = "your_key_here"
BAIDU_OCR_SECRET_KEY = "your_key_here"
```

---

## 第五步：启动项目

```bash
python app.py
```

启动成功后，终端会显示：

```
* Running on http://0.0.0.0:5001
```

在浏览器中访问：[http://localhost:5001](http://localhost:5001)

---

## 常见问题

**Q：安装 pymupdf 报错？**  
A：确保 pip 版本较新，执行 `pip install --upgrade pip` 后重试。

**Q：上传文件后提示 API 错误？**  
A：检查 `app.py` 中的 API 密钥是否正确填写，以及网络是否能访问 Dify / DeepSeek 服务。

**Q：端口 5001 被占用？**  
A：修改 `app.py` 最后一行的 `port=5001` 为其他端口号，例如 `port=5002`。
